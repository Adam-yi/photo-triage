# 照片筛选判定规范 v1.0

状态：**目标规范，供实现与验收使用**。本文件不能被解释为当前脚本已达到全部条款。当前实现差距见第 12 节。

## 1. 目标、边界与判定单位

1. 输入为用户指定目录及其子目录中的静态照片；跳过视频、符号链接、已有筛选结果目录。不得上传原片或分析数据。
2. 系统只读取原片并在源目录下新建带时间标识的结果目录，按原字节复制照片。不删除、覆盖、重命名、移动原片，也不依据筛选结果执行删除。
3. 同目录、同文件主名的 RAW、JPEG、HEIF 等版本组成一个**照片单元**。质量判断可以使用可解码的高质量预览；分类和复制必须覆盖该单元全部文件。不能把 RAW 和 JPEG 当作两张相似照片。
4. 每个照片单元恰好进入一个文件夹：`推荐保留`、`相似照片待挑选`、`有明显问题`、`无法判断`。内容类型是内部标签和报告字段，不增设内容类型文件夹。
5. 系统的目标是减少人工复选量：找出同一拍摄意图的替代照片并推荐组内一张，同时标出有充分证据的明显问题。它不替用户决定审美价值、故事意义或删除对象。
6. 一张照片可能属于多种题材。所有判断均应保留可追溯的“主体—状态—证据—结论”；模型分数、拍摄时间、连续文件名均不是单独的结论。

### 1.1 输入可用性

| 情况 | 处理 |
|---|---|
| JPEG、PNG、TIFF、WebP、HEIF/HEIC、RAW 等可解码 | 按原有色彩方向正确读取预览，保留原始字节用于复制。 |
| RAW 无法解码，但同单元 JPEG 可解码 | 用 JPEG 判断，两个文件同类复制；报告注明判断依据。 |
| 整个单元无法解码或预览损坏 | `无法判断`，不得猜测内容和质量。 |
| 很小、极端裁切、画面大量遮挡 | 可识别的事实照常记录；不足以判断质量或相似关系时进入 `无法判断`。 |
| EXIF 时间缺失、错误或时区不明 | 只降低时间证据权重；不得据此断言不相似。 |

## 2. 统一的两层内容分类

第一层记录**画面含有什么**，允许多标签；第二层确定**主要比较对象是什么**。例如“人在花海里”可同时有“人物、花草、风景”，但主比较对象可能是人物，也可能是花海。主要对象由画面占比、位置、清晰区、拍摄序列的一致性共同决定；无法确认则保留多个假设并降低判定置信度。

| 一级题材 | 必须识别的常见子类或属性 | 主比较对象 |
|---|---|---|
| 人物 | 单人、多人、自拍、背影、剪影、活动人物；面部可见性、身体可见范围 | 指定人物或人物组合及其动作 |
| 宠物 | 猫、狗、鸟等家养动物；单只或多只 | 同一动物及其姿态、神态 |
| 野生动物 | 鸟类、昆虫、鱼、其他野生动物 | 同一动物或同一群体及行为 |
| 自然风景 | 山、水、海、森林、草地、雪景、日出日落 | 同一视角下的主要地形与视觉事件 |
| 天空与天象 | 云、月亮、星空、彩虹、烟花 | 同一视觉事件及形态阶段 |
| 植物花卉 | 单花、花束、花海、树木、叶片、微距 | 同一花朵或植株；花海可按景观处理 |
| 建筑与街景 | 建筑外观、室内、街道、地标、店面、夜景 | 同一建筑或街景主体及视角 |
| 食物饮品 | 单菜、组合餐、饮品、菜单 | 同一道菜、同一摆盘或同一桌面意图 |
| 物品与商品 | 静物、纪念品、产品、收藏品 | 同一物件及展示角度 |
| 交通工具 | 车辆、船、飞机、缆车等静态或动态主体 | 同一车辆或同一运动阶段；作为风景元素时按风景处理 |
| 文字与信息 | 文件、票据、标牌、屏幕、海报、二维码 | 同一信息内容与可读区域 |
| 艺术与展品 | 绘画、雕塑、装置、展览 | 同一作品及必要的整体/细节视角 |
| 活动与表演 | 舞台、运动、仪式、聚会、游行 | 同一事件瞬间或动作阶段 |
| 混合与未知 | 多主体、抽象图像、无法可靠识别的新题材 | 保留具体可见对象；不足时 `无法判断` |

规则：标签用于选择证据，不直接触发相似分组；“人物”标签不能覆盖画面中真正作为主体的食物、建筑或景观。模型不得推断身份、关系、年龄、种族、职业或情绪原因。未列出的题材允许新增标签，不得硬塞入最相近旧标签。

## 3. 判定顺序与四类输出

### 3.1 顺序

1. **盘点与配对**：枚举文件、排除视频和已有结果、识别格式、将同次拍摄的 RAW/JPEG 等组成照片单元。
2. **预览可用性**：旋转方向、读取色彩和预览。失败则标记 `无法判断`，但仍可复制原文件。
3. **内容与主体**：多标签识别、确定主比较对象和其可见程度。保留题材不确定性。
4. **整图到局部的初判**：先确定题材、主要对象及背景关系，再检查与该题材有关的局部（如人脸、动物头部、菜品、文字或关键景物），并综合清晰度、曝光、噪声和遮挡。必须收集完相关证据后才能给初步类别；单一弱信号只形成提示。该步不得因“已有更好一张”而判为问题。
5. **候选场景**：用拍摄时间、地点、背景、连续序列、视角建立宽松候选；任何一个线索不得独立定组。
6. **替代关系**：按题材核对主体、状态、构图和拍摄意图。反证优先于相似分数。
7. **成组**：组内任意两张都应可相互替代。若长序列出现渐变，拆成多个组，不用链式传递合并。
8. **分类后验证**：对每个可解码照片单元重新读取源文件，使用不裁掉边缘的整图视角再次识别内容，并重新测量多区域与主体局部的清晰度、明暗、人脸或文字。逐张核对初判理由是否真的涉及主要对象，再利用同动作相似组寻找反证。无论主体标签是否改变，都复核初次分组遗漏的近邻候选；当拍摄时间、局部几何细节和画面内容共同支持同一主体时，重新成组，必要时替换与新证据冲突的初步组。共享背景或时间不能单独触发合并；人物脸部、动作和文字信息仍遵守更严格规则。最终成组后才选优；证据冲突而不足以改判时列入 `无法判断`。全图明暗与主体曝光矛盾时复核主体；边缘可疑区域未覆盖主体时不把它当成无法判断；同一表情在组内持续出现时不轻率断言抓拍失态。第二遍须使用新读取的像素与不同取景证据，不能只重复第一遍的缓存分数。
9. **组内推荐**：根据验证后的类别先排除明显问题，再按题材质量规则推荐一张；其他可接受照片为 `相似照片待挑选`。
10. **输出与人工复选**：复制文件、写简短理由和组号；用户可根据结果继续选择。

### 3.2 输出优先级

| 条件 | 分类 | 备注 |
|---|---|---|
| 无法解码或关键判断证据不足 | `无法判断` | 不得虚构质量或相似结论。 |
| 明确影响主拍摄目的的严重问题 | `有明显问题` | 即使处于相似组，也进入此类；保留组号和相对最佳标注。 |
| 无明显问题，且是相似组最佳候选 | `推荐保留` | 一组通常只推荐一张。 |
| 无明显问题，但组内已有推荐照片 | `相似照片待挑选` | 表示可以人工比较，不等于建议删除。 |
| 无明显问题，没有可信替代组 | `推荐保留` | 不能因“无法找到相似”而降级。 |

如一个相似组全部有明显问题，全组均进 `有明显问题`，只在标注中指出相对较好的一张，不把有问题的照片强行送入 `推荐保留`。`无法判断` 仅用于关键质量或内容证据不足、且该疑点确实影响选择的照片；轻度噪声、局部暗背景等弱信号应写入简短提示，不得单独改变类别。

## 4. 通用相似分组标准

**成组顺序**：先对候选对收集取景、局部对应、主体状态及拍摄时间证据，再从证据最强的照片对开始成组。扩展已有组时，每个新成员都要与全部成员兼容；不能因为文件扫描顺序使一张较弱的候选占住组，导致更强的照片对分离。内容模型的主标签只是线索；同一物体因近景与远景被标成不同题材时，可用局部几何对应和极近的拍摄时间纠正，但人物正背面、明显动作变化和文本内容变化仍是反证。

### 4.1 同组必须同时满足

1. **同一主拍摄对象**：同一人物/动物/菜品/作品/地形，或同一活动瞬间。多个对象时，主要对象组合一致。
2. **同一可替代状态**：人物主要动作相同，宠物姿态或行为阶段相同，食物摆盘与拍摄目标相同，景观是同一视角与视觉事件。允许微小头部、手指、云形或光线变化。
3. **相近构图意图**：主体大小和位置、横竖幅、取景范围、前后景关系足够接近，使一张能替代另一张。允许轻微平移、倾斜、缩放或重拍。
4. **无强反证**：出现明确不同主体、动作、朝向、表情意图、菜品、作品、文字内容或叙事瞬间时必须分组。
5. **证据充分**：至少两类相互独立的正面证据，例如主体局部对应与背景几何对应；时间/文件名只作辅助。模型整体向量相近不能单独定组。

### 4.2 强制分组边界

- 同一人物在同一位置：正面与背面、站立与坐下、举手与不举手、抱宠物与不抱宠物、展示物品与未展示物品，原则上分组。
- 轻微低头、转头、眨眼、手指细节变化：若身体动作和取景意图不变，可归同组；眨眼造成质量问题另行判断。
- 人像中显著不同的镜头距离或横竖构图，例如环境人像与面部特写，通常分组；除非二者裁切后表达完全同一意图且其他证据充分。
- 同一景点但视角、地形关系、天气事件或前景主体改变，原则上分组。
- 同一餐桌上的不同菜，必须分组；同一道菜与整桌合影，通常分组。
- 同一文本标牌的正反面、不同页、不同内容，必须分组；同一页的清晰重拍可归同组。
- 文件号相邻、时间接近、色彩相近、同一背景或同一个内容标签，均**不足以**单独合并。

### 4.3 冲突处理

先看硬性反证，再看支持证据。若视觉模型说“相似”，但主体分割显示人换成猫、姿态显示举手变垂手，或 OCR 显示文字内容变化，则不得自动同组。若两种可靠证据冲突，标为“待人工确认”，不要强行合并；该单元可进 `无法判断`，或保持独立 `推荐保留` 并在标注中提示候选关系。不得把低置信度推断伪装成事实。

## 5. 分题材的相似、质量与选优规则

以下“明显问题”必须达到第 6 节证据标准。一般的审美差异不构成问题。每类的选优先级按顺序比较；前项差距明显时，不用后项抵消。

| 题材 | 同组正面证据 | 必须分开的情况 | 质量与组内最佳候选 |
|---|---|---|---|
| 单人人像 | 同一人物、背景与镜头距离；躯干、双臂和手中物位置一致；小幅低头/转头允许。 | 正背面变化；坐/站/蹲变化；手持物、举手、拥抱等主要动作变化；明显不同构图意图。 | 先看面部可辨识与眼睛，再看主体焦点、自然瞬间、姿态完整、面部曝光，最后看背景干净程度。 |
| 多人合影 | 人员组合与站位、互动动作一致；每个人的脸都能逐个检查。 | 有人加入/离开、站位互换、核心互动改变。 | 优先所有重要人物眼睛可见、脸部清晰且无遮挡的照片；不能只看中心人物。 |
| 背影/剪影人像 | 同一人或稳定服装轮廓、位置、朝向和手臂动作；背景几何与色彩相符。 | 回头露正脸、转身、举手/放手、显著换姿态；轮廓不确定时保守。 | 优先主体轮廓完整、关键边缘清楚、背景与主体分离、曝光符合剪影意图。 |
| 宠物和野生动物 | 同一动物或同一群体，姿态、头向、四肢、位置和行为阶段相近。 | 卧/坐/跑/跳变化；嘴叼物、抬爪、回头、互动对象变化；不同动物。 | 优先眼睛/头部清晰，关键动作抓拍完整，耳、尾、爪等重要部位未意外裁切；高速运动允许背景虚化。 |
| 山川、海景、城市全景 | 地形/天际线、地标相对位置和视角一致；移动的云或小型车辆不是主角。 | 镜头方向、前景主体、远近层次或横竖取景意图明显不同。 | 优先地平线和关键地形清晰、亮暗层次保留、构图稳定；雾、逆光、长曝光不能一概判错。 |
| 天空、云、日落、烟花 | 同一视觉事件且云形、光束、烟花阶段和取景接近。 | 不同烟花爆发、日落阶段或天体位置构成不同瞬间；构图叙事改变。 | 优先关键形态完整、亮部仍有层次、运动轨迹符合意图，画面无明显抖动。 |
| 花草与微距 | 同一花朵/植株/花束、花瓣状态、焦点和取景相近。 | 花朵不同、开放状态不同、单花与花海、整体与纹理微距。 | 优先目标花蕊或预期焦平面清晰、花瓣完整、遮挡少；背景虚化可接受。 |
| 食物和饮品 | 同一道菜/饮品、同一摆盘、主角位置和拍摄角度近似。 | 不同菜；单菜与整桌；食用前后；摆盘已改变；俯拍与侧拍表达不同信息。 | 优先主菜清晰、色泽自然、关键配料完整、盘缘和餐具无意外遮挡；热气或浅景深可接受。 |
| 建筑、室内、街景 | 同一建筑/街道主体，同一面或相近透视和取景。 | 建筑正面与侧面、外观与室内、全景与装饰细节、不同店铺或街口。 | 优先主体几何清楚、重要部位完整、曝光层次与透视可接受；有意的仰拍或广角不视为错误。 |
| 物品、商品、展品 | 同一件物品或同一作品、相近朝向、可见面和取景。 | 物品不同；正反面；整体与标记/纹理细节；开箱前后。 | 优先物体边缘与重要细节清晰、反光不过度遮挡、颜色可信、轮廓完整。 |
| 交通工具 | 同一车辆或同一交通场景，行进位置/姿态和取景意图相近。 | 车辆不同、运动阶段构成不同叙事、外观与车内、整体与标志特写。 | 优先主体清晰、轮廓完整、运动模糊符合意图；车牌可读性不作为默认目标。 |
| 文件、标牌、屏幕、二维码 | 同一页/同一屏/同一标牌内容及近似取景。 | 内容、页码、屏幕状态不同；重要文字区域不同。 | 可读性为第一优先级：无严重反光、失焦、透视遮挡或裁掉关键文字；二维码须完整。 |
| 活动、运动、表演 | 同一人或群体、同一动作阶段与场景；连拍中的细小帧差。 | 起跳与落地、挥手与鼓掌、表演不同动作、不同情节节点。 | 优先关键瞬间、脸或行动主体清晰、动作完整；有意的动感模糊允许。 |
| 艺术、抽象和混合内容 | 先确定主作品或主视觉对象；视觉结构和取景意图一致才同组。 | 整体与细节、不同作品、不同观看角度呈现新信息。 | 按其主要记录目的选优；无法推断意图时不以常规人像/风景审美强判。 |

### 5.1 混合题材路由实例

- 人占画面较大、手中拿花：按人像动作比较，花是动作证据。换成另一种花可能构成新拍摄意图。
- 人只占山景一小部分且前后地形为视觉主体：按风景比较；但人站位的显著改变可使构图不再互相替代。
- 餐厅桌面上有人举杯：若人和举杯是主体，按人像/活动；若重点是菜品特写，按食物。
- 宠物坐在花丛中：宠物表情和姿态优先；若宠物只是远景点缀，则按景观。路由不确定时不得强并。

## 6. 明显问题的证据标准

**总原则**：问题必须影响主拍摄目的，并由可观察证据支持。阈值随主体大小、分辨率、景深、拍摄类型变化；不得用一个全图锐度值横扫所有照片。凡是可能为有意艺术效果、拍摄条件无法判断或主体太小的情况，转 `无法判断` 或保留人工复核标注。

**多区域复核**：风景中的山体、天空或远景因大气、景深而较柔和，不能仅凭中央区域低锐度降级；检查前景、远景及关键地标是否各有可辨细节。相反，人物面部或动物主体明显失去细节时，背景、标牌或家具很锐利不能替主体“抵消”问题。动物处于高亮环境时，同时检查大面积高光裁切、主体轮廓与纹理，而非只看全图亮度。

| 问题 | 可判为“明显”的条件 | 不得单独据此判错 |
|---|---|---|
| 主体失焦 | 应清晰的主要对象缺乏可辨细节，而同一平面附近或背景更清楚；高质量预览确认。 | 背景虚化、柔焦风格、远景低纹理、缩略图看不清。 |
| 相机抖动或运动拖影 | 主要对象及静态参照共同出现方向一致的明显拖尾，使目标无法辨认。 | 流水、车灯、烟花、舞台和运动摄影中的有意拖影。 |
| 曝光异常 | 主要对象的关键明暗细节大面积不可恢复地丢失，影响记录目的。 | 有意剪影、日落高反差、舞台暗调、雪景和逆光。 |
| 高噪声或压缩伪影 | 在目标区域大面积破坏细节，并经放大核对；同组其他照片有明显更可用细节可辅助判断。 | 夜景自然颗粒、RAW 预览偏差、社交媒体再压缩但主体仍清楚。 |
| 意外遮挡与裁切 | 主要对象的关键部分被路人、手指、镜头盖、边框等挡住或截断，表达目的受损。 | 有意特写、局部肖像、建筑细节、花瓣微距。 |
| 镜头污点、眩光、反射 | 大面积覆盖主体且不是画面意图，明显妨碍辨认。 | 有意逆光光斑、橱窗反射、舞台灯效。 |
| 人物瞬间表情 | 面部足够大且清晰，可可靠确认半闭眼伴随无意张口、打哈欠等不利瞬间，并与连拍其他帧的自然状态相符。单纯闭眼不足以成立。 | 有意闭眼摆拍、正在笑/说话/唱歌/吃东西、眨眼瞬间无法分辨、面部太小或被遮挡。 |
| 动物瞬间状态 | 眼部或头部严重失焦、关键行为被遮挡，或意外眨眼且同组有清晰帧。 | 打哈欠、吐舌、甩头等可能正是有趣瞬间。 |
| 文字记录失败 | 关键文字/二维码被裁断、失焦、眩光遮挡，无法完成信息记录目的。 | 不是以文字为主体的街景中的不可读背景招牌。 |

### 6.1 人脸与表情的专项规则

1. 必须逐个检查画面中足够显著的人脸，记录“可评估/不可评估”；多人的照片不能只看最大人脸。
2. “闭眼”应结合眼睑形态、眼部局部清晰度、脸部朝向和连续帧比较；侧脸、低头、强光眯眼不能仅凭单帧地标比值判错。眼部开合度数值较低不能证明眼睛闭合：低头注视也可能得到同样数值，标注应写可观察的数值特征和不确定性，不能断言“闭眼”。嘴部放松的闭眼摆拍或低头注视不属于明显问题，应保留为相似组候选。眼部开合度较低且张嘴时意图不明，先列为 `无法判断`；若另有可靠证据证实短暂失态，才可列为 `有明显问题`。
3. 张口**不是**独立缺陷。若照片意图是微笑、说话、欢呼或唱歌，张口可完全正常。只有张口与半闭眼、面部不协调等同时出现，并有清晰证据显示是短暂不利瞬间，才进入 `有明显问题`。
4. 连拍中同视角、同场景且间隔很短的照片可作表情反证：一帧眼部开合明显低于前后清晰帧，且没有相近的连续闭眼帧，才可标注“疑似眨眼瞬间”。连续多帧低眼部开合更可能是有意摆姿，不因邻近一张睁眼就判废。双手或头部位置只在单帧中偏离稳定姿态，先列 `无法判断` 并标注“动作是否完成”；不能把摸头发、看向下方、闭眼本身当作缺陷。
4. 用户指出的 `IMG_7818` 类型应作为“人物特写、张口且眼睛未完全睁开”的回归样本：如果原片证据足够且没有明显的说话/欢呼意图，应判 `有明显问题`。不能用文件号直接写规则。
5. 系统不判断“漂亮/难看”“情绪好/坏”等主观评价；只判断具体可见状态。无法核实的表情留给人工复核。

## 7. 组内最佳照片的决策次序

1. **有效候选**：排除本规范第 6 节的明显问题；不可判定质量的照片暂不自动胜出。
2. **主体是否成功记录**：人物脸/宠物眼/菜品/文字/景观关键形态是否可见且清楚。多个重要主体时，优先兼顾全部主体。
3. **题材关键瞬间**：表情、动作峰值、动物姿态、光照时机、烟花形态、菜品未被食用等。只在有明确证据时比较。
4. **技术质量**：主体局部清晰度、曝光层次、噪声、压缩、遮挡。以关键区域优先，不能只看全图平均值。
5. **构图完整性**：意外裁切、倾斜、背景干扰、主体大小；不同拍摄意图本应分组，不能在同组内以构图大改变量“选优”。
6. **无法拉开差距**：采用稳定、可复现的确定性规则选一张（例如较清晰、再按拍摄顺序），在报告中写“差异很小，请人工复选”，不得宣称客观优胜。

最佳照片只表示该相似组内的**技术与可观察瞬间推荐**。不得用人脸美貌评分、肤色、年龄、性别、身份或商业价值来排序。候选中存在明显问题时，进入 `有明显问题`，不得仅因“组里比较好”升级为保留。

## 8. 置信度、证据与人工复核

### 8.1 三档证据

| 档次 | 含义 | 自动动作 |
|---|---|---|
| 高 | 主体、状态、构图都有一致证据且无反证；质量问题可在目标区域清楚复核。 | 可自动成组或标记明显问题。 |
| 中 | 部分证据支持，但小主体、遮挡、低分辨率或模型冲突。 | 给出候选关系/待复核原因；不得做强烈质量结论。 |
| 低 | 解码失败、主体不明、意图不明或证据互相冲突。 | `无法判断` 或保持独立并标记待复核。 |

### 8.2 标注字段

每照片单元的记录至少包含：相对路径、所有配对文件、结果类别、内容标签、主比较对象、朝向或状态、相似组号、组内是否推荐、判断依据、不确定原因。长篇逐张报告不面向聊天展示；聊天只提供数量汇总和少量重要限制，完整记录供用户按需查看。

标注用观察性语言，例如“同一猫的正面卧姿；本张眼部更清晰”。避免“相似度 0.83 所以重复”“表情不好看”这类不可直接复核或主观表达。模型分数可以写入调试日志，但不能当作用户理解结论的唯一理由。

## 9. 参数与校准办法

本规范故意不规定一个通用的“相似度 ≥ 0.8”或“锐度 < 12”阈值。不同题材、焦距、分辨率、RAW 预览、低光和构图条件下，这些数值不可直接互换。实现应为各题材维护独立参数，并在人工标注的数据上确定；任何调整都要跑全部题材回归集。

参数至少分成：场景候选宽松门槛、主体一致性门槛、状态一致性门槛、硬反证门槛、明显问题门槛、人工复核区间。**宽松候选门槛只决定是否继续比较，不决定最终成组**。优先优化漏掉的真实替代照片，同时用硬反证和完整组兼容性控制误合并。

不应通过只修改 `IMG_7301` 或 `IMG_7378` 的文件号规则修复问题。修复应描述一般失败类型，并在不同地点、不同主体和不同拍摄设备中验证同一原则。

## 10. 验收样本与指标

### 10.1 标注集建设

1. 从真实文件而非文件管理器缩略图建立样本；保留 RAW/JPEG 配对、EXIF 与解码失败样本。测试集不得混入用于调参的照片。
2. 覆盖第 2 节全部题材与混合题材，以及明亮/夜景、横竖图、近远景、低纹理、运动、多人、遮挡、艺术效果。
3. 每种题材均有三类成对样本：明确应同组、明确不应同组、合理观察者可能分歧的边界样本。每类明显问题也包含正常反例。
4. 由至少两名人工标注者独立判断；意见不一致的照片进入边界集，不当作机器的确定性正确/错误。
5. 每次变更检查全量回归：新增正例不能使原有负例被合并；新增缺陷规则不能把有意效果误打为明显问题。

### 10.2 建议发布门槛（须在真实标注集验证，当前未达成声明）

| 指标 | 建议门槛 | 解释 |
|---|---:|---|
| 明确替代照片的成对召回率 | 各主要题材 ≥ 95% | 避免大量漏分组；样本不足不得合并计算掩盖弱项。 |
| 明确非替代照片的不误合并率（特异度） | 各主要题材 ≥ 98% | 特别保护不同动作、菜品、人物朝向和文字内容。 |
| 明显问题的精确率 | ≥ 98% | 尽量减少把正常瞬间误放入问题目录。 |
| 人工认为组内推荐不劣于其他候选 | ≥ 90% | 主观意见分歧时另计，不伪装成唯一正确答案。 |
| 原片保护 | 100% | 前后文件数量、大小和校验值一致；重复运行不覆盖旧结果。 |
| 文件处理记录 | 100% | 每个发现的照片文件都被复制或明确记录失败原因。 |

这些是验收目标，不是现有模型的性能宣称。还须记录各题材数量、误合并与漏分组样本、`无法判断` 比例及运行耗时，避免单靠总体准确率掩盖局部失败。

## 11. 非功能与安全验收

- Windows 和 macOS 均需在各自环境完成安装、格式解码、只读计划和复制运行的实测；“Python 可运行”不等于跨平台已验收。
- 一次运行离线完成，不访问网络；输入原片和分析中间数据不得上传。
- 运行前检查目标空间；复制出错逐文件记录，不删除已复制文件或原片。下一次运行使用新结果目录。
- 几百张照片的运行时间应在目标设备上实测，按“解码、内容识别、相似搜索、复制”分段记录，设置可接受目标后再称为完成性能验收。
- 相似分组和质量判断应可重复：相同输入、模型、参数产生相同类别与组内推荐，除结果目录时间戳外保持稳定。
- 用户最终人工选择优先于算法。系统不得生成任何自动删除命令、删除清单或隐含删除动作。

## 12. 当前实现与本规范的关系

当前 `photo-triage` 脚本已具备：本机处理、原片复制、四类输出、RAW/JPEG 单元、基础问题检测、多标签与主比较对象分离、按主要题材选择不同的相似门槛和选优权重、人物朝向与姿态比较、离线文字识别后的保守内容比较，以及少量宠物、风景、食物的真实原片回归样本。

**尚不能宣称完全符合本规范**：全部题材尚无分别校准的识别、分组、质量和选优规则；混合题材的主拍摄对象判断仍是启发式的，多人逐人判断也只经小样本验证；无法可靠识别动物眼部、菜品关键部位，文字识别错误或内容过少时也不能自动确认同页；完整人工标注集、Windows/macOS 双平台与最终版整批性能验收均未完成。现有自动测试仅证明有限样本未回归，不能外推为表中发布指标已达到。

参考依据：

- [OpenAI CLIP 模型卡](https://huggingface.co/openai/clip-vit-base-patch32)：模型卡说明其细粒度分类等能力有限，类别设计会影响表现，因此内容标签和相似分数只作证据，必须做场景内验证。
- [Google MediaPipe Face Landmarker 文档](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker)：面部关键点可作为可见状态的测量工具，但“表情是否值得保留”仍需本规范的情境判断。
